# Langues du site

| Langue | URL | État | Indexation |
|---|---|---|---|
| Français | `/`, `/biens`, … | référence, complet | oui |
| Anglais | `/en`, `/en/biens`, … | complet (vérifié par le typage) | oui (`hreflang`, sitemap) |
| Wolof | `/wo`, `/wo/biens`, … | **partiel, à relire** | non (`noindex`) |

## Fonctionnement

- Dictionnaires : `src/i18n/messages/fr.ts` (référence), `en.ts`, `wo.ts`. La forme du français définit le
  type `Messages` : une clé manquante en anglais est une **erreur de compilation**.
- Le wolof est un `DeepPartial<Messages>` : toute clé absente s'affiche en français (fusion clé par clé).
  Un bandeau en tête de page l'indique au visiteur.
- Les pages sont les mêmes pour toutes les langues (`src/app/router.tsx`) ; les liens internes passent par
  `@/i18n/Link`, qui ajoute automatiquement le préfixe de langue.
- Le sélecteur FR · EN · WO (en-tête, menu mobile) garde la page **et les filtres** en cours.
- SEO : `lang` sur `<html>`, canonical par langue, `hreflang` fr/en + `x-default`, `og:locale`, sitemap
  bilingue. Prix et dates formatés selon la langue (`150,000,000 FCFA` en anglais).

## Contenus qui restent en français

- **Les annonces** (titres, descriptions, caractéristiques libres) : elles sont saisies en français dans le
  back-office. En anglais, la fiche le signale et la description SEO est générée en anglais. Les types de
  biens et les équipements, eux, sont traduits (référentiels connus).
- Paramètres de l'agence (`agency_settings` : description, slogan, textes SEO).
- Messages d'erreur de champ renvoyés par le backend : remplacés en anglais par un texte générique.
- Wolof : mentions légales, confidentialité, une partie du catalogue et des formulaires.

Pour traduire les annonces, il faudrait des colonnes multilingues côté backend (ex. `title_en`,
`description_en`) et leur saisie dans le back-office : évolution à demander à l'équipe backend.

## Demandes reçues dans une autre langue

Les messages envoyés depuis `/en` ou `/wo` sont préfixés `[Langue du visiteur : EN]` pour que
l'équipe réponde dans la bonne langue. Les sujets (« Je souhaite investir »…) sont toujours transmis en
français, langue de travail de l'agence.

## Relecture du wolof (à faire avant indexation)

La traduction wolof est un premier jet qui doit être relu par un locuteur natif (de préférence quelqu'un
de l'agence, pour le vocabulaire immobilier utilisé avec les clients : « alal », « luwe », « néeg »…).

1. Relire et corriger `src/i18n/messages/wo.ts` ; compléter les clés manquantes en s'appuyant sur `fr.ts`.
2. Retirer le bandeau : vider `common.languageNotice` dans `wo.ts`.
3. Activer l'indexation : `indexable: true` pour `wo` dans `src/i18n/config.ts`, puis ajouter `wo` à
   `INDEXED_LOCALES` dans `scripts/generate-seo-files.ts`.

## Ajouter une langue

1. Ajouter le code dans `LOCALES` et `LOCALE_META` (`src/i18n/config.ts`) et dans l'expression de
   `splitLocale`.
2. Créer `src/i18n/messages/<code>.ts` et l'enregistrer dans `I18nProvider.tsx`.
